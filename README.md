# Login System Testing

An individual academic project focused on testing a web-based Login Authentication System using manual and automation testing techniques.

## Testing Techniques

* Manual Testing
* Black Box Testing
* Equivalence Class Partitioning (ECP)
* Boundary Value Analysis (BVA)
* Automation Testing

## Automation Tool

* Selenium IDE

## Test Scenarios

* Valid Login
* Invalid Password
* Empty Username
* Empty Password
* Invalid Username

## Project Documentation

The project documentation contains test cases, testing results, and screenshots demonstrating the use of Selenium IDE for automated testing.

## Skills

Software Testing, Manual Testing, Automation Testing, Selenium IDE, Black Box Testing
